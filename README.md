# 数学家庭教师

对话式数学讲解的开源副本。网页和安装包只负责收发，讲题、登录和错题库在你自己的服务上。

私人开发仓库不在这里。这个副本已经去掉学生信息、学校名称和原部署地址。

## 自己跑起来

1. 复制 `backend/.env.example` 为 `backend/.env`，填入你自己的模型钥匙和管理员口令。
2. 在 `backend` 目录安装 `requirements.txt` 里的依赖，然后启动：`uvicorn main:app --host 127.0.0.1 --port 8300`。
3. 管理页是 `http://127.0.0.1:8300/admin`。
4. 手机安装包编译时加上 `--dart-define=API_BASE=你的服务地址`。不写时，应用连本机 `http://127.0.0.1:8300`。

产品说明见 `产品说明.md`。界面用色见 `DESIGN.md`。
